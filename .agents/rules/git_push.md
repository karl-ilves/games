# GitHubi automaatne uuendamine (Git Push Nõue)

Iga kord, kui muudad koodi ja \`node verify_game.js\` testid on edukalt läbitud, **pead alati lisama muudatused giti, looma selge commit sõnumi ning tegema \`git push\` GitHubi repole**.

**Kuidas teha:**
\`git add .\`
\`git commit -m "kirjeldus tehtud muudatustest"\`
\`git push\`

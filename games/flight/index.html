✈️ Flight Simulator Pilot Manual

W / S: Throttle Up / Down (0% to 100%, Afterburner on Fighter)
Up / Down Arrows (or S / W): Pitch Elevator (Up pushes nose down, Down pulls nose up to climb!)
Left / Right Arrows (or A / D): Roll Ailerons (Banking turns)
Q / E: Rudder Yaw / Runway Nosewheel Steering
G: Retract / Extend Landing Gear
F: Cycle Flaps (0° Clean, 15° Takeoff/Approach, 30° Full Landing)
B: Wheel Brakes / Airbrakes
P: Autopilot (Maintains target altitude and levels wings)
C: Cycle Camera (Chase 3D, Cockpit 1st Person, Wing Cam, Flyby)
J: Toggle Anti-Ice System
